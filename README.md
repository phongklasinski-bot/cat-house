# cat-house

微信小程序猫咪养成小游戏。当前项目使用原生微信小程序结构，无 npm 依赖，第一阶段已完成首页、基础页面、猫猫接金币小游戏原型和本地存档数据结构。

## 微信开发者工具运行步骤

1. 安装并打开微信开发者工具。
2. 登录微信开发者工具账号。
3. 点击工具栏中的“编译”。
4. 编译成功后，模拟器会默认打开首页 `pages/index/index`。
5. 如需清空测试存档，可在微信开发者工具中打开“调试器 > Storage”，删除 `cat-house-save`，然后重新编译。

## 项目导入步骤

1. 克隆仓库：

```bash
git clone https://github.com/phongklasinski-bot/cat-house.git
```

2. 打开微信开发者工具。
3. 点击“导入项目”。
4. 项目目录选择克隆后的 `cat-house` 根目录。
5. AppID 可选择：
   - 使用自己的小程序 AppID。
   - 或选择测试号 / 游客模式。
6. 确认项目名称为 `cat-house`。
7. 点击“导入”，等待微信开发者工具加载项目。

## 测试流程

### 1. 项目启动测试

1. 导入项目后点击“编译”。
2. 确认页面能进入首页。
3. 确认顶部资源栏显示金币、小鱼干、体力。
4. 确认首页猫屋场景、猫咪、小游戏入口和底部导航入口显示正常。

### 2. 首页交互测试

1. 点击首页猫咪。
2. 确认猫咪文案会随机变化。
3. 点击“猫猫钓鱼”或“猫猫抓老鼠”。
4. 确认出现“即将开放”提示。
5. 点击“猫屋建设”“猫咪图鉴”“鱼类图鉴”。
6. 确认对应页面可以打开。

### 3. 猫猫接金币测试

1. 在首页点击“猫猫接金币”。
2. 进入小游戏页面后点击“开始游戏”。
3. 使用左右按钮移动猫咪。
4. 或在游戏区域中拖动，确认猫咪可以跟随横向移动。
5. 接住金币后，确认得分和金币数增加。
6. 接到毛线团后，确认得分不会低于 0。
7. 倒计时结束后，确认显示结算弹窗。
8. 点击“再玩一次”，确认可以重新开始。
9. 点击“返回猫屋”，确认可以回到首页。

### 4. 存档测试

1. 完成一局猫猫接金币。
2. 返回首页。
3. 确认金币数量已增加。
4. 重新编译项目。
5. 确认金币数量仍保留。
6. 如需重置，删除 Storage 中的 `cat-house-save`。

## 开发说明

- 当前项目不需要执行 `npm install`。
- 当前项目没有构建步骤，直接用微信开发者工具导入根目录即可运行。
- 本地存档 key 为 `cat-house-save`。
- 后续新增小游戏时，建议复用 `utils/storage.js` 和 `utils/game-state.js` 中的存档更新方式。
